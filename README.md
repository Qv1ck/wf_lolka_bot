# WF Lolka Bot

Бот для [Lolka](https://lolka.app) по игре Warframe. База варфреймов, модов и оружия собирается автоматически из официальных Public Export манифестов Digital Extremes — ручное обновление при выходе патчей больше не нужно.

## Быстрый старт

```bash
npm install          # зависимости
npm run generate     # собрать базу из Public Export (data/*.json)
npm test             # офлайн-проверки поиска и embed'ов
```

Создай `.env` в корне:

```
LOLKA_TOKEN=токен_бота_из_портала_разработчика
GUILD_ID=id_сервера   # необязательно: команды появятся на этом сервере мгновенно
```

```bash
npm start
```

Токен выдаётся в [Портале разработчика](https://lolka.app/developers) (вкладка «Бот»). Бота нужно добавить на сервер по ссылке авторизации из раздела OAuth2.

## Команды

| Команда | Что делает |
| --- | --- |
| `/search <название>` | Варфрейм: способности, Гельминт, статы, где добыть, неделя Цепи Дувири, прайм-версия со ссылками на warframe.market |
| `/mod <название>` | Мод: полярность, редкость, стоимость, статы ранга 0 и макс |
| `/weapon <название>` | Оружие: урон (ур/пр/реж), крит, статус, скорострельность, неделя инкарнон-ротации |
| `/circuit` | Текущая неделя Цепи Дувири: варфреймы и инкарнон-оружия Стального Пути |

Все команды с автодополнением, понимают русские и английские названия, а также народные прозвища (`некр` → Nekros, `абизян` → Wukong) из `tools/manual_aliases.json`.

## Источники данных

- `content.warframe.com/PublicExport` — официальные манифесты DE (RU + EN): имена, способности, статы, моды, оружие. Обновляются с каждым патчем игры;
- `drops.warframestat.us` — таблицы дропа WFCD (места фарма частей, содержимое реликвий);
- `wiki.warframe.com` (Module:Warframes/data) — Гельминт-способности;
- `github.com/calamity-inc/browse.wf` (live.ts) — полное расписание Цепи Дувири (11 недель варфреймов, 9 недель инкарнон-оружия);
- `api.warframe.market/v2` — проверка слагов и иконки прайм-сетов (опционально, при недоступности слаги строятся по правилам).

## Обновление базы

Бот сам проверяет каждые 6 часов, не началась ли новая игровая неделя, и при смене недели пересобирает базу и перечитывает её на лету — перезапуск не нужен. Вручную после патча:

```bash
npm run generate
```

Никакой ручной правки JSON. Ручные справочники `manual/` (Гельминт, недели Дувири) оставлены как запасной вариант на случай недоступности внешних источников.

## Структура

```
src/bot.js               — бот: команды, embed'ы, поиск
tools/generate_data.js   — генератор базы из Public Export
tools/manual_aliases.json— ручные алиасы (народные прозвища)
data/                    — сгенерированная база (в git не хранится)
test/offline_test.js     — офлайн-проверки без подключения к Lolka
```
